A luxury, dark-first personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**. Designed for **$0 hosting on GitHub Pages** with an integrated local Portfolio Manager and GitHub Actions CI/CD.

---

## 🌟 Highlights & Features

- **Personal Brand & Identity**: Communicates authentic curiosity, diligent learning mindset, and flexible career direction in AI and emerging technologies.
- **Visual AI Journey**: Interactive evolutionary roadmap (`Computer Science → Programming → Python → AI Exploration → Generative AI → Automation → AI Projects → What's Next?`).
- **Currently Exploring**: Dynamic focus grid highlighting Artificial Intelligence, Generative AI, Python, Automation, n8n, and core Computer Science fundamentals.
- **Skills (Honest Assessment)**: Transparent competencies categorized into Programming, AI & Automation, and Tools with status badges (*Currently Focused*, *Building*, *Exploring*, *Learning*). **No CSS listed as a personal skill and no fake percentage bars.**
- **Data-Driven Projects Catalogue**: Supports categories (*All, AI, Automation, Web, Experiment, Client, Learning*) and detailed modal case studies (*Overview, Problem, Idea, Approach, Technologies, Features, Result, What I Learned*).
- **$0 Architecture Portfolio Manager**: Built-in local CMS tool allowing you to add, edit, feature, and delete projects with 1-click **Export to `projects.json`** for Git-based updates.
- **Direct Contact Channels**: 1-click email copy & mailto links for `ghimireprabal2@gmail.com` and `prabinghimire2065@gmail.com`, plus direct verified links to GitHub, LinkedIn, and Instagram.
- **Accessibility & SEO**: Semantic HTML, keyboard accessibility, OpenGraph metadata, `robots.txt`, `sitemap.xml`, and SVG favicon.
